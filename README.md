# PaceFetch - Free Private PDF Tools

**Light PDF tools that just work. Free, fast, private.**

PaceFetch is a 100% client-side PDF toolkit. Merge, split, compress, convert PDF to Word, JPG to PDF - all in your browser. No uploads, no storage, no tracking. Your files never leave your device.

Live: **https://pacefetch.com**

### ✨ Features - 13 Tools (All Offline)

**ORGANIZE**
- Merge PDF ◫ - Combine multiple PDFs
- Split PDF ✂ - Split by page or size
- Rotate PDF ↻ - Rotate pages
- Delete Pages ✕ - Remove unwanted pages
- Add Page Numbers #️⃣
- Add Watermark ◍

**CONVERT**
- PDF to Word W - Most Popular
- Word to PDF D
- JPG to PDF 🖼
- PDF to JPG JPG

**OPTIMIZE & SECURE**
- Compress PDF ⤓ - To 100kb, 200kb, etc
- Protect PDF 🔒 - Add password
- Unlock PDF 🔓 - Remove password

All processing happens locally using pdf-lib + pdf.js. Zero server costs.
